# 📸 Photo Gallery

## Project Overview
Photo Gallery is a React-based web application that allows users to upload, search, view, and manage images in a modern and user-friendly interface.

## Features
- User Login & Signup
- Image Upload
- Image Gallery
- Search Images
- Category Filter
- Favorites
- Slideshow
- Responsive Design

## Technologies Used
- React.js
- Vite
- JavaScript
- CSS
- Node.js
- MongoDB
